Catatan

  • File Excel harus memiliki header: Nama Guru (A), Username (B), Mata Pelajaran (C), dan jumlah rombel per kelas (D-O).
  • Extract mengelompokkan per tingkatan (X, XI, XII, XII DKV) - baris = mata pelajaran, kolom = kelas, isi = username guru.
  • Jika tidak ada kolom Username, otomatis pakai Nama Guru. Jika satu mapel di kelas yang sama diajar lebih dari 1 guru, digabung dengan |.
  • Klik pada sel untuk menyalin isi, atau gunakan tombol Salin Semua / Download CSV.
