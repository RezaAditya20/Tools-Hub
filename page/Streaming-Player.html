Catatan: Tool ini membutuhkan TorrServer + proxy server.

Setup (3 langkah):
1. Download TorrServer dari GitHub → jalankan TorrServer-windows-amd64.exe
2. Jalankan proxy: node streaming-server.js (atau double-click start-streaming.bat)
3. Buka http://localhost:8091 di browser

Kenapa proxy? Browser memblokir akses langsung ke TorrServer dari file HTML lokal (CORS). Proxy mengatasi ini.
