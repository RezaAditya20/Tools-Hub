Address Fixer

Perbaiki & pecah alamat jadi kolom terstruktur (jalan → kode pos), siap export Excel.

1. Input Alamat

Paste alamat (satu per baris) atau tarik file .txt ke area bawah.

Satu alamat per baris. Baris kosong diabaikan. Otomatis deteksi RT/RW, Kelurahan, Kecamatan, Kota, Provinsi, dan Kode Pos. Teks HURUF KAPITAL otomatis diubah ke proper case (contoh: Jl. PADEMANGAN IV GG.21 NO.4 → Jl. Pademangan IV Gg.21 No.4), sedangkan RT/RW, singkatan (SDN, SMP, DKI, dst.) dan angka romawi tetap kapital.

Tarik & lepas file .txt di sini, atau klik untuk pilih file
